# caesar-cipher
A command-line tool for encryption of a message using the Caesar Cipher. 
This was built as a project to understand Python and cryptography fundamentals. 

## What it does

Encrypts any message by shifitng it a certain number of spaces

## What I learned

 How the Caesar cipher works and why it's easy to crack, as well as how to work around using the ord() and chr() functions in order to code a way in which it is somewhat beginner friendly. 


## Why it matters

The Caesar cipher is one of the oldest encryption methods in history.
Understanding its weaknesses is a foundation for learning why modern
encryption (like AES) exists and why simple ciphers aren't secure.

## Example
Enter message: Hello World
Enter shift: 3
Encrypted: Khoor Zruog
